## MaliPDF 1.0.7

MaliPDF is on the **Mac App Store** and the **Microsoft Store**; both keep it up to date automatically. A DMG for Apple Silicon Macs is attached below for direct download.

### New
- **Smoother pen**: live strokes are drawn as you move the pen, and only the newest part is redrawn, so long strokes stay fluid on 120 Hz screens. A light starting stroke no longer begins with a heavy dot.
- **Library and Cloud Sync**: keep documents on this device or sync them through iCloud Drive or a cloud folder (OneDrive, Dropbox…).
- **Tablet mode** for touch screens: bigger buttons; the pen draws, one finger scrolls and two fingers zoom (status bar button or Settings).

### Fixed
- Cloud Sync: a conflict always keeps both versions; a cloud index that can't be read stops the sync instead of overwriting newer files; two different documents with the same name are kept apart; deleted documents no longer come back; changes made while syncing are kept.
- Cloud Sync only uses folders you chose or detected cloud folders.
