MaliPDF 1.0 is the first stable release: a fast desktop app for annotating, teaching from and organizing PDFs on macOS and Windows. Free, no account, and your files stay on your computer.

## Download

| Platform | File |
|---|---|
| Mac with Apple Silicon (M1 and later) | `MaliPDF-macOS-Apple-Silicon.dmg` |
| Mac with Intel processor | `MaliPDF-macOS-Intel.dmg` |
| Windows 10 / 11 (64-bit) | `MaliPDF-Windows-x64-Setup.exe` |

> **First launch on macOS:** this build is not yet signed by Apple. If macOS says the app cannot be opened, right-click MaliPDF in Applications, choose **Open**, then **Open** again. You only need to do this once.

## What's new since 0.9 beta

**Writing and annotating**
- Sticky notes, text highlight / underline / strikethrough that select letter by letter, and annotation tags with a tag filter.
- Shapes in one button (line, arrow, rectangle, ellipse, polygon), distance and area measurement with a drawing scale, and a ruler.
- Handwriting to text, and ink replay.
- The eraser now only erases ink and drawings — pictures and inserted pages are removed with Select + Delete.
- Opacity can be changed on existing annotations.

**Pages and documents**
- Inserting a PDF adds its real pages (text stays searchable); PowerPoint files come in as printout pages.
- Combine and split documents, crop pages, header / footer / page numbers / watermark, reduce file size, export pages as images, and create a PDF from images (HEIC and TIFF supported).
- Edit the PDF's own text, fill in PDF forms, and recognize text in scanned pages (OCR, macOS).
- Much smaller files when photos are inserted (a 31 MB note now saves at 1.5 MB).

**Workspace**
- Turkish and English interface (Settings ▸ Appearance ▸ Language).
- A tidier toolbar with File, Page, Insert and PDF menus; fit and layout buttons in the status bar.
- Side-by-side view, move a tab to its own window, night / sepia page modes, focus and presentation modes with a laser pointer.
- Note templates (Cornell, to-do, weekly, meeting, music), snapshot to clipboard, and a new app icon.
