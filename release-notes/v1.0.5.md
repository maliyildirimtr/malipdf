## MaliPDF 1.0.5

MaliPDF is on the **Mac App Store** and the **Microsoft Store**; both keep it up to date automatically. A DMG for Apple Silicon Macs is attached below for direct download.

### New
- **Select text and copy it**: with the Select tool, the cursor becomes a text cursor over the page's text. Drag to select (or double-click a word), then Copy or Highlight — Cmd/Ctrl+C copies.
- **Go to a page**: type a page number in the status bar and press Enter.
- **Colours in Focus Mode**: four colours under Undo / Redo; double-click one to pick another colour. The presentation bar uses the same colours and keeps them with every tool.
- **Text style bar while writing**: the font, size, colour and border bar also appears while typing with the Text tool.
- Documents open with the **whole page in view**.

### Windows
- A classic Windows layout: a slim title bar with the document name, then MaliPDF's menus and tools, then the document tabs — no more doubled menus.
- Shortcuts are shown as Ctrl+C, Ctrl+Shift+S… instead of Mac symbols.

### Fixed
- **Eraser**: erased ink no longer comes back when the pen is lifted.
- **The bottom of every page was cut off** by about 30 pixels (e.g. a slide's footer line); pages now show in full.
- A zoomed-in page can be scrolled all the way to its left edge; less space between pages.
- The Night Mode button next to Settings was removed (it is in Settings ▸ Appearance and View ▸ Night Mode).
